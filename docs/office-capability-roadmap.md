# COCCE Office capability matrix and roadmap

COCCE Office is a growing local-first productivity suite, not yet a replacement for Microsoft Office or GenOffice. The current modules perform real work, but native-file compatibility, broader editing models, and several AI surfaces remain future work. This roadmap adopts public feature concepts only; no GenOffice source code is used.

## Verified capability matrix

| Area | Status | Working now | Important gaps |
|---|---|---|---|
| Docs | Partial | Browser-local rich text; headings 1–3; paragraph, bold, italic, underline, strikethrough, lists and quotes; autosave/recovery; Markdown export; bounded local DOCX import/export for text, lists, and simple rectangular tables; local review comments anchored to selected text with open/resolved state, mapped highlights, orphan handling, and sidecar persistence; selection-based AI actions, prompt-only drafts and preview-before-insert. Full-document summaries require explicit confirmation. | No full DOCX fidelity, page layout, images, merged/nested/complex table fidelity, DOCX comment import/export, tracked changes, citations, mail merge, cloud sync or collaboration. AI generation is currently unavailable when the fixed free endpoint is rate-limited. |
| Sheets | Partial | Local workbooks and worksheets; a bounded visible grid; cell/formula editing; tested local formulas including `IFERROR`, `COUNTIF`, and `SUMIF` (without wildcard criteria); CSV import/export; confirmed local XLSX import/export for one visible 24×12 worksheet with text, finite numbers, booleans, and supported same-sheet formulas; bounded arrow/Tab/Enter navigation; Shift+Arrow/Shift-click range selection; local TSV copy/paste that preserves raw formulas and quoted tabs/newlines; one-dimensional local arithmetic-series fill from two finite numeric seeds; overwrite confirmation and atomic local save. XLSX import validates the whole bounded ZIP/XML package before adding a new workbook, and export requires a fidelity confirmation. Export types canonical numeric raw values and uppercase TRUE/FALSE only; noncanonical number/boolean-like strings and whitespace-only cells are refused rather than changed. | No full XLSX/Excel compatibility, cell formatting, charts, pivot tables, data validation, broad Excel formula compatibility, formula/date/text series fill or AI-generated sheets. XLSX import/export is limited to 288 cells and refuses unsupported workbook content; formatting, dates, hidden/merged layouts, macros, and cached formula results are not retained. |
| Slides | Partial | Local text decks; three themes; title/body/notes; four per-slide text layouts (title/content, two columns, quote, section divider) used in editing, presenter, and print output; add, duplicate, delete and reorder slides; bounded active-presentation undo/redo for content, theme, layout, and ordering (50 session steps; rapid field typing coalesces); JSON transfer; print-to-PDF; presenter navigation and optional speaker notes. Older or unknown layout values fall back to title/content. Undo/redo uses the existing local save/recovery path; history resets on reload. | No PPTX, master slides, full layout designer, images, shapes, charts, transitions, animation, media, cloud collaboration or AI-generated decks. Presentation creation, import, and whole-deck deletion are not in the undo stack. |
| PDF | Partial | Local viewing and selectable text; multi-occurrence search (up to 2,000) with temporary hit overlays, wraparound previous/next navigation, current-hit scroll focus, and explicit clear-search; local selected-text highlights, comments, underlines and strike-throughs; 50-step session undo and confirmed current-page clear; page rotation, extraction, reorder and merge as new copies. Text-mark vectors reproject from normalized page rectangles after resize and rotation. An explicit, confirmation-gated **Create annotated copy** action verifies mark fingerprints against exact local PDF bytes and writes a separate PDF with flattened highlight/underline/strike-through page content; comments, quote text, and notes are excluded, and the original bytes/sidecar stay unchanged. Output is capped at 25 MB, 500 pages, and 10,000 rectangles; marked pages must have verified PDF.js/pdf-lib geometry and in-bounds CropBoxes. | No OCR, direct text/image editing, editable PDF annotation objects for local marks, form creation, signatures, secure redaction or cloud review. Export refuses encrypted/malformed PDFs, unverified legacy marks, non-quarter-turn or inconsistent page geometry, oversized inputs/outputs, and CropBoxes extending outside MediaBox because renderers can disagree. Digital signatures and advanced form behavior may not be preserved. |
| AI | Partial | User-invoked Docs selection tools and prompt-only drafting; local reusable recipes; preview/undo; separately confirmed, bounded plain-text document summaries. Provider key stays server-side. | No Sheets/Slides/PDF AI authoring, no autonomous/background workflows, no full-document indexing, and no paid or alternate-provider fallback. Last production smoke returned temporary free-model unavailability (upstream rate limit); successful generation is not currently verified. |
| Files and collaboration | Partial | Browser-local Drive/Vault and a separately server-backed Office Teams feature using existing COCCE accounts. | Personal Docs/Sheets/Slides/PDF files are not cloud-synced or shared. Office Teams does not make local personal files collaborative. Native Office-format round trips are absent. |

The initial editor tranche adds local Docs H3/strikethrough, bounded Sheets navigation, presenter-only Slides speaker notes, and bounded multi-occurrence PDF search, alongside responsive toolbars. The DOCX tranche adds local import/export for text, lists, and simple rectangular tables; the Docs table slice adds cell editing, row/column controls, sanitizer and size guards, and local persistence. Unsupported import tables flatten with warnings, and unsupported export tables are refused; this is not a full OOXML round trip. The Sheets tranche adds Shift+Arrow range selection, local TSV clipboard operations that preserve raw formulas, one-dimensional numeric arithmetic-series fill, and bounded local XLSX import/export. XLSX import creates a new workbook only after explicit confirmation and complete ZIP/XML validation; export also requires a fidelity confirmation. The accepted subset is one visible 24×12 worksheet, ordinary text, finite numbers, booleans, and formulas supported by the local engine with same-sheet references. The current formula increment adds lazy `IFERROR` (without masking cycles), plus `COUNTIF` and `SUMIF` with exact or relational criteria, case-insensitive text matching, type-matched relational comparisons (not-equal also matches unlike types), a 256-character cap on evaluated text criteria, a 512-character formula-text cap, a 10,000-cell formula-range cap, and same-shape `SUMIF` ranges; wildcard expansion is unsupported. XLSX includes these calls only when their references remain visible and conditional ranges have compatible shapes. Export uses canonical numeric raw values and uppercase TRUE/FALSE as typed cells; noncanonical numeric/boolean-like text and whitespace-only values are rejected to avoid silent coercion. Unsupported workbooks or cell structures fail before save; the import limits compressed/expanded sizes, ZIP entries, XML parts, populated cells, and text. Formatting, dates, metadata, row/column sizing, print/view settings, and cached formula results are not retained. The Slides tranches add 50-step per-presentation session undo/redo and four per-slide text layouts, with old/invalid layout values falling back to title/content; layout switching preserves text/notes and is rendered by editing, presenter, and print/PDF views. Undo/redo results are saved locally; the history stack itself is not persisted across reloads. PDF follow-ups add transient search-hit overlays and selected-text underline/strike-through marks. The text marks share the normalized local sidecar with highlights/comments, reproject through rotation/resize, and support a 50-step session undo plus confirmed page clear. The new annotated-copy action is separately confirmed and source-hash-bound; it flattens only verified highlights/underlines/strike-throughs into a new local PDF's page content, excludes comment/quote/note text, and never modifies source bytes or the sidecar. Geometry is checked against PDF.js view boxes and pdf-lib MediaBox/CropBox; in-bounds offset crops and 0/90/180/270 rotations have rendered synthetic coverage. Ambiguous out-of-bounds CropBoxes and unsupported geometry are rejected. Output caps are 25 MB, 500 pages, and 10,000 mark rectangles. The local output is visual, not editable PDF annotation data, and may not preserve signatures or advanced form behavior.

## Practical roadmap

1. **Polish and harden the existing local editors.** Continue with accessible toolbar groups, mobile layouts, keyboard paths, import/export limits, save/recovery feedback, and non-destructive operations. Add component tests before expanding control surfaces. This phase must not imply cloud backup or file compatibility.
2. **Add one bounded authoring capability at a time.** Candidate increments: richer Docs table formatting/selection; Sheets safe cell formatting, more tested formulas, formula autofill and AI-generated-sheet previews; Slides master-slide editing, a fuller layout designer, and local images with alt text; PDF OCR or safe local form editing only after separate format and signature reviews. Define schema and round-trip behavior before each feature.
3. **Expand user-controlled AI across editors.** Build prompt-to-sheet and prompt-to-slide as typed-prompt-only flows with a validated structured preview and explicit apply step; consider PDF actions only on text the user selects. Reuse the existing fixed free endpoint, retain the 55-day/no-training disclosure, and keep failure retryable—never silently switch to paid or alternate models. The current upstream rate limit blocks verification of successful generation.
4. **Extend native formats cautiously.** Docs handles only a bounded local DOCX subset, and Sheets now handles a bounded one-visible-sheet XLSX subset. Full DOCX fidelity and full XLSX/PPTX compatibility, cloud files, shared annotations, version history, OCR, signatures, and real-time editing need independent format/security reviews, compatibility fixtures, authorization design, retention rules, and owner approval before implementation or claims of support.

The Docs review-comments tranche adds a versioned localStorage sidecar scoped by workspace and document, capped at 200 comments per document, 2,000 records and 2 MB total. Quotes are limited to 1,000 characters and notes to 2,000. Open comments highlight only when the text at their mapped ProseMirror range still exactly matches the saved quote; changed passages remain saved but unhighlighted as orphaned comments. Resolve/reopen/delete stay local, and confirmed local document deletion cleans only that document's comment scope. Comment data is excluded from rich text, DOCX/Markdown exports, and AI requests. This is not OOXML comments, shared review, or tracked changes.

This matrix describes verified capability boundaries, not a claim of feature parity. New controls should appear only when the underlying behavior, tests and data boundary are ready.


## Docs table range selection update

The table-selection portion of roadmap item 2 is now implemented: users can select the active row, active column, or whole simple table and apply the existing bold, italic, underline, or strikethrough tools across its cells. The selection count is announced in the toolbar; the selection itself is temporary. Formatting stays within the current sanitized table markup, uses the ordinary local undo/save path, leaves review-comment sidecars unchanged, and does not widen the DOCX table schema. Component tests cover all three selection scopes, multi-cell marks, undo/redo, local patching, comment-sidecar stability, and export markup; DOCX fixtures cover supported inline-mark round trips. The next Docs table work should address only one additional format at a time—such as alignment or column sizing—after defining safe sanitizer and DOCX round-trip behavior. Cell shading, merged/nested cells, full Word fidelity, and cloud collaboration remain out of scope.


Cell-range selection is formatting-only: it does not authorize an excerpt AI request or a selected-text review comment. Prompt-only drafts remain prompt-only, and table text is included in AI only by the separately confirmed full-document summary action. Preview insertion is blocked while a cell range is still selected.
